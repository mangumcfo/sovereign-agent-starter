Construction (bit-decomposition + Schnorr-OR, Fiat-Shamir):
  Prove value ∈ [0, 2^bits) for a Pedersen commitment C = value*G + randomness*H, no reveal:
   - commit each bit  Ci = bi*G + ri*H, with Σ 2^i ri == randomness  (=> Σ 2^i Ci == C);
   - per bit, a Schnorr OR-proof that Ci opens to 0 OR 1 (branches over base H: Ci, or Ci - G);
   - verify: every bit OR-proof valid AND Σ 2^i Ci == C.
  Built ONLY from primitives already PRESENT (Pedersen + Schnorr over the sealed L1 curve). No new L1.
  Threshold "v ≥ m" = the range proof on the difference commitment C - m*G.

Soundness (tested, mandatory): out-of-range prover REFUSES; a proof bound to a different commitment
  rejects; a tampered bit-commitment rejects; a tampered OR-proof response rejects; a proof of the
  wrong bit-width rejects. In-range (incl. edges 0 and 2^bits-1) accepts.
